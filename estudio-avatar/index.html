Gerar a voz

Gera o áudio do texto novo com a voz que você escolher no Fish Audio.

Gerar no site do Fish Audio
Baixar áudio para o DreamFace
Chave da API do Fish Audio

Pegue a chave no site do Fish Audio, no menu de API Keys. O ID da voz é o código que aparece no endereço da página da voz. A API cobra créditos separados do plano do site; o modelo S2.1 grátis evita esse custo.

5

Animar a boca no DreamFace

fora do app
  1. Baixe o áudio novo no passo 4 (aqui ou no site do Fish Audio).
  2. No DreamFace, use o vídeo do passo 1 e troque o áudio pelo novo.
  3. Salve o vídeo animado na galeria e volte aqui.
